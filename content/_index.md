# B Frames

Examples and experiments for Cloudflare Stream that pull from Developer Docs,
player library documents, and experiments I've built for learning and testing.

## Experiments and Demos

**[Transformationizer](https://transformationizer.tsmith.net/):** Experiment with
Media Transformations to edit and optimize short-form videos dynamically.

**[Magic Mirror](https://magic-mirror.tsmith.net/):** See ultra low glass-to-glass
latency in action by comparing a local webcam view and a WebRTC relay with Stream Live.

**The [Cinema](https://cinema.tsmith.net/)** demo platform, powered by Stream's
new bindings and event subscriptions, combine native and third-party inference
services to show how video understanding can contribute to application experience.

**Allowed Origins Demo:** See basic behavior of a the built-in player on a
[denied](https://bad-origin.tsmith.net/) origin, compared to an
[allowed](https://good-origin.tsmith.net/) origin.

**[LL-HLS Demo](https://llhls.tsmith.net/):** Demoing the latest state of
Stream's support for low-latency HLS, by way of a beautiful part of Colorado.
