# B Frames

Examples and experiments for Cloudflare Stream that pull from Developer Docs,
player library documents, and experiments I've built for learning and testing.

## Experiments and Demos

See ultra low glass-to-glass latency in action on the
**[Magic Mirror](https://magic-mirror.tsmith.net/)**. Compare a local webcam
view and a WebRTC relay with Stream Live.

How does Stream's **Allowed Origins** work? See an
[allowed](https://good-origin.tsmith.net/) origin and a
[denied](https://bad-origin.tsmith.net/) origin.

The [Cinema](https://cinema.tsmith.net/) demo platform, powered by Stream's new
bindings and event subscriptions, combine native and third-party inference
services to show how video understanding can contribute to application experience.
